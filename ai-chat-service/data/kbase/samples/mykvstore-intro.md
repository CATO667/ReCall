# mykvstore 简介

mykvstore 是一个用 C 实现的内存 KV 存储，兼容 RESP2 协议，支持 pipeline。

## 核心能力

- 四种存储引擎：dict、数组、红黑树、跳表
- 持久化：WAL 增量日志 + SAVE 全量快照
- 主从同步：RDMA 全量 + eBPF 增量转发

## 适用场景

适合作为 AI 聊天系统的 QA 缓存、会话上下文存储，以及文档 chunk 元数据索引层。
当用户提问时，可以先从向量库检索相关 chunk，再结合 LLM 生成回答。

## 切分建议

文档入库时推荐使用 recursive 策略：优先按段落切分，单块不超过 512 字符，重叠 64 字符以保留上下文连续性。
